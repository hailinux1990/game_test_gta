🎮 PIXEL CITY - Installation Guide

Open World GTA-style 3D Game

📋 Quick Start

Important: Simply double-clicking index.html WILL NOT work on other machines.

⚠️ Security Notice: Modern browsers block web games from loading when opened directly from files.
You must run a local web server to allow the game to load scripts properly.

🖥️ Windows Users

  1. Extract all files from the ZIP to any folder
  2. DOUBLE-CLICK on launch.bat
  3. Wait for server to start (it will show a command prompt)
  4. OPEN your browser and go to: http://localhost:8123
  5. The game will start automatically!

🐧 Linux Users

  1. Extract all files from the ZIP to any folder
  2. Open terminal in that folder
  3. RUN: chmod +x launch.sh
  4. EXECUTE: ./launch.sh
  5. Wait for server to start (it will show output)
  6. OPEN your browser and go to: http://localhost:8123
  7. The game will start automatically!

📱 Mobile Users

If you have a smartphone with the same WiFi network:

  • Launch the server on your computer
  • Find your computer's IP address (e.g., 192.168.1.100)
  • Open browser on phone and go to: http://192.168.1.100:8123
  • Game will work on any mobile browser!

🎮 Game Features

  • 3D Open World: 11×11 blocks, 4 unique cities
  • GTA-style Mechanics: Wanted system, car theft, police chases
  • Vehicle Physics: Realistic driving with 60Hz fixed timestep
  • Weapon System: Hand, knife, pistol (100 bullets), AK-47 (500 bullets)
  • Procedural Content: All terrain generated automatically
  • Sound Design: Complete audio with WebAudio API
  • Mobile Optimized: Touch controls and responsive design

📖 Game Controls

Keyboard:

WASD / Arrows — Move
Shift — Run
Mouse — Aim and shoot
1/2/3/4 — Switch weapons (hand/knife/pistol/AK-47)
E — Enter/steal vehicles
R — Reload guns

Touch/Mobile:

Virtual joystick for movement + tap to attack/shoot

🔧 Troubleshooting

🖥️ If game doesn't load

  1. Refresh your browser completely
  2. Check console (F12) for JavaScript errors
  3. Ensure server is running (look for terminal output)
  4. Try different browser (Chrome, Firefox, Edge)
  5. Disable ad blockers temporarily

📱 Mobile specific issues

  • Touch not working: Try different browser (Chrome/Firefox)
  • Slow loading: Wait for server to fully start
  • Orientation: Use landscape mode for best experience

🆘 Need help?

If you're still having issues, the game includes debug_bridge.cjs for troubleshooting.

🏆 System Requirements

  • Browser: Chrome, Firefox, Edge, or Safari (modern versions)
  • Memory: 2GB+ RAM recommended
  • Graphics: WebGL support (most browsers have this)
  • Storage: ~10MB for game files
  • Network: Not required (works offline)
⚠️ Note: The game includes a headless mode for systems without GPU acceleration.
